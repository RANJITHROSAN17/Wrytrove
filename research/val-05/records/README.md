# Local VAL-05 records

This directory is Git-ignored except for this README. Put local coded rows here, for example `observations.csv`, copied from [the header-only template](../observation-template.csv).

Rules:

- Use only the columns and codes in [the codebook](../observation-codebook.json).
- No free text, quotes, document excerpts, personal paths, prompts, recordings, screenshots or personal identifiers.
- Run `npm run study:check` after every session.
- Generate an aggregate with `npm run study:aggregate`. Review it manually before attaching anything to issue #69 or issue #56.
- Delete local rows after the approved aggregate is published, within 90 days, or immediately if consent is withdrawn.
- Never add a raw row to a commit or issue comment.

There are no observations in this directory yet.
