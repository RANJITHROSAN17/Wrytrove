# Participant consent script

Read this aloud before setup. Use plain language and allow questions. A participant may decline any part and still take part in the rest, unless declining would make the task impossible.

> Thank you for helping test an early preview of Wrytrove. This is a usability study of the software, not a test of you. We want to see which tasks are clear, which are confusing and whether the editor works with assistive technology.
>
> You will use only synthetic files prepared by the study team. Please do not open your own documents, type personal information, paste private text or use a real provider key. If that starts to happen, we will stop and reset the test copy.
>
> We will observe task completion, time, errors, hesitation and comprehension. We record these as codes and counts, not as your words or document contents. The study sheet uses a session code instead of your name. We do not need your contact details in the study record; scheduling information, if any, is kept separately and deleted after the session.
>
> There is no product telemetry in this study. The study tools do not contact a network. Optional AI tasks use synthetic text and stop before any provider request. We will not send your text to a model or cloud provider.
>
> Screen recording and voice recording are off by default. If a separate recording is proposed, it is entirely optional, stays on a local device, is shown to you if you ask, is never committed to the repository and is deleted after analysis or on request. You can still participate if you say no to recording.
>
> If you use a keyboard only, Narrator, NVDA, high scaling, high contrast or another access method, we will record only a condition code and the software version in a separate environment log. We will not ask for medical details or a diagnosis.
>
> You can pause, skip a task or stop the session at any time without giving a reason. Stopping will not affect any separate support or contribution relationship. If you stop, we will delete the local coded rows from that session unless you explicitly ask us to keep them.
>
> After the session we publish only aggregate counts and controlled finding codes. A human reviews the report before it is attached to an issue. We will not publish your name, contact details, file paths, document contents, prompts, recordings or personal identifiers. The software is still an early preview, so please do not use it as the only copy of important work.
>
> Do you have any questions? Do you agree to take part under these conditions?

Record only a yes or no answer in a private local checklist. Do not record the participant's name beside the answer. If the answer is no, thank them and end the session. If consent is withdrawn later, stop and delete that session's local rows.

## Facilitator reminders

- Use a disposable Windows profile and synthetic fixtures.
- Never ask for a real file, a real provider key or a personal prompt.
- Do not promise anonymity beyond the controls described above; a small study can still carry context risks.
- Do not promise payment, fixes or a release date. Any compensation is agreed separately and is not part of the observation record.
- If a participant becomes uncomfortable, stop first and handle data cleanup afterward.
