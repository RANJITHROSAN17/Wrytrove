# Recovery decision rehearsal

VAL05-PRIVACY-RECOVERY-SYNTHETIC-FIXTURE-LOCAL-DRAFT-IS-NOT-A-BACKUP

Scenario: a draft exists locally while an ordinary saved file remains the source of truth. Recovery can help after an interruption, but it is not a replacement for deliberate saving or a separate backup.

Questions to consider:

- What does Wrytrove store locally when recovery is enabled?
- How would you turn recovery off and remove the local draft?
- Which copy would you keep if the disk file changed outside the editor?

No real document, personal path, provider key or credential belongs in this rehearsal.
