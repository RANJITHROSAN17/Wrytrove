# VAL-05 synthetic fixtures

Every file in this directory is invented for the study. There are no real user documents, personal paths, prompts from participants, credentials, recordings, screenshots or personal identifiers. No fixture loads a network resource.

Copy this tree into a **disposable** Windows workspace before a session. Do not edit the committed originals. Reset from the checksum manifest between tasks and participants. If a participant types personal text, discard the disposable copy and start again.

`manifest.json` is generated by:

```sh
node scripts/validation/study-evidence.mjs fixtures research/val-05 --write
```

`npm run study:check` verifies every fixture checksum and scans the study kit for prohibited artifacts. A fixture change requires a new protocol version and approval before recruiting.
