# Announcement checklist

VAL05-ASSISTIVE-ANNOUNCEMENT-SYNTHETIC-FIXTURE-NAMES-ROLES-AND-STATES

Check that a screen reader can identify:

- the editor and the active tab;
- a named dialog and its close control;
- a search result and its source state;
- a review accept or reject action;
- a dirty, saved or stale status message;
- a progress message and an error message.

Use stable names and roles. Do not rely on color or position alone.
