# Keyboard route

VAL05-ASSISTIVE-KEYBOARD-SYNTHETIC-FIXTURE-FOCUS-ORDER-AND-RETURN

1. Open a tab and confirm the active tab name.
2. Edit one short line and save it.
3. Open search and return to the editor.
4. Open settings, change one control and restore it.
5. Close the dialog and confirm focus returns to the editor.

The route must work without a pointer, with visible focus and without a trap.
